# Automatic memory: first increment

2026-10-03. Implemented conversation-local capture, lifecycle and bounded activation in Conclave; Converse receives the shared engine through the source-commit/hash migration.

`memory.js` owns a versioned, event-backed ledger independent of context snapshots. `memory-extractor.js` captures exact explicit user clauses and defines the bounded candidate schema. `memory-controller.js` admits captures before answering and selects binding commitments/alternatives before lexical optional memories. Context and Agent share this path; Agent capture runs before its first answer call under the run's cancellation, deadline and token guards.

Automatic memory is projected separately rather than writing every retained record into always-protected named state. This supplies the lifecycle/activation bridge without adding a generic-compaction exception in Store.commit. Model `update_state` passes an authority gate. User constraints cannot be replaced by assistant arithmetic; model recommendations stay unresolved.

Corrections preserve prior heads; ambiguous corrections preserve alternatives. Message revisions, file versions/removal and declared transitive dependencies invalidate on replay. Suppression, supersession and invalidation exclude linked raw context/source passages and declared assistant/reasoning descendants from ordinary model lookup. Human inspection and canonical export retain history. API edits/suppression use an independent memory revision; hosted sequence/revision/lease fencing covers event-only writes. No database migration or permanent worker was added.

The production service enables optional candidate extraction; injected test/library providers use deterministic capture unless enabled explicitly. The proposer sees one source of at most 4,000 characters and four short heads, returns at most eight unresolved candidate spans, uses 600 output tokens and a 12,000-byte/15-second allowance, and has no tools. One model call is shared by a current capture and a bounded retry. Purpose/usage records count its overhead. Source persistence precedes model spending. Span validation is not semantic or factual validation.

The first full source run caught an input-order assumption in a service fixture; it now checks the complete input for document content. A later unconstrained parallel run hit the existing 200 ms shadow-estimator allowance and produced one fewer timing review. The test passed in isolation; a full run at concurrency two passed 199 checks with one optional saved-export replay skipped. Twelve dedicated memory fixtures passed, including PostgreSQL hydration, manual corrections, stale revisions, capture cancellation/retry and restart. Syntax checks passed. Desktop/mobile Memory editor verification and downstream migration are recorded in Converse's corresponding report.

This increment establishes fixture invariants. It does not establish general answer-quality, latency or cost improvement. Conservative grammar can miss instructions, objective boundaries inside Context are not inferred, and optional extraction remains unresolved. Automatic capture reads human messages/objectives; broader tool/document capture, episode consolidation, learned policies, resumption packets and cross-chat ownership remain future work.
