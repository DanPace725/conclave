## Architecture and current capabilities

- **Conclave is the engine source of truth.** Author, test and commit shared changes here, migrate to Converse, verify byte parity and run its checks before committing the snapshot. Converse owns its application UI and deployment. Local commits, publication, deployment and real-client acceptance are separate stages.
- The engine provides SQLite/PostgreSQL append-only history, versioned context/state, source recovery, projections, compaction, pins, streaming GPT/Claude inference, checkpointed Agents, workspace files, native search and bounded public-page retrieval. See [README](README.md), [images](docs/IMAGES.md), and [testing](TESTING_GUIDE.md).
- Automatic memory keeps human commitments/corrections distinct from external/model claims, with source-linked inspection and guarded suppression. Jev and embeddings are optional. CLP evidence brokerage is opt-in; declared provenance is not proof of truth. The cost controller remains in shadow mode: smaller working context does not establish lower total cost or better answers. See [memory](docs/AUTOMATIC_MEMORY.md), [CLP](docs/CLP_BROKER.md), and [cost-controller evidence](docs/archive/2026-10-03/context-cost-controller.md).
- Hosted conversation identity and encrypted provider keys are owner-scoped. A request may spend only its resolved credentials; explicit missing keys never fall back to environment keys. Conclave's independent hosted handoff service does not run inference or require model keys.
- **Hosted handoffs are independent of Converse and local stores:** Railway service, separate Neon database/Auth and Conclave account sign-in. Explicit save/find/retrieve tools retain immutable revisions, exact comparisons, retry deduplication, owner isolation and OAuth read/write/revocation guards. A real ChatGPT → Claude → ChatGPT → Claude round trip was recorded October 7; it is historical evidence, not a fresh release check. [Hosted setup](docs/HOSTED_HANDOFFS.md) · [Account evidence](docs/archive/2026-10-07/hosted-account-roundtrip.md)
- CLAMP 1.0 Clyps preserve complete ORMD within 1,500 o200k_base tokens. Readable references remain stable after title changes; explicit links pin account-owned revisions. The shared read-only dashboard/MCP App supports project filtering, history, differences, export and a bounded connections graph with pointer-anchored wheel zoom, pinch, drag, Fit and keyboard controls. The graph loads no linked context automatically. [CLAMP](docs/CLAMP.md) · [UI](docs/PLUGIN_UI.md) · [Pilot](docs/CLAMP_PILOT.md)
- Local stdio/loopback MCP and coding plugins remain separate installations. `conclave_local` distinguishes the local connection from hosted Conclave. Configuration generation does not install, authenticate or synchronize accounts. Restart/fresh-session client acceptance is distinct from fixture tests. [Local/coding setup](docs/HANDOFF_SETUP.md) · [Coding integration](docs/CODING_INTEGRATIONS.md)

## Open work

- Hosted distribution: real-app revocation/reconnection and restart/redeploy recovery, public listings, operational cleanup/retention and permanent deletion, hosted import and additional clients. Consumer Gemini custom-connector availability is unestablished. New graph gestures still need real ChatGPT desktop/Android acceptance.
- Clyps: live continuation-quality trials, useful budget ranges, arbitrary ORMD editing/import, stable independent idea/project identities, dependency closure beyond one boundary hop and durable-memory promotion. Existing explicit links are not inferred relationships.
- CLP: portable bundles/sidecars, signed trust/frame/resolver registries, policy membranes and unresolved review, vector/graph brokerage, exploratory recall, calibrated confidence/separation and coherence/attention telemetry.
- Retrieval/state: broader filter-aware semantics, quality calibration, durable vector backfill, approximate-index tuning, heading/TOC lookup; resolved/archive lifecycle, confirmation/proposal status, semantic conflicts and revision-conflict diffs.
- Memory/portability: ordinary conversation JSON import, explicit cross-conversation ownership/corrections, embedding-assisted correction targeting, episode consolidation, learned policies, resumption packets, broader document/tool capture and image sharing across chats.
- Workspace/web: file rename/version diffs, richer pin controls, private scratch/artifact handoffs, JavaScript rendering/PDF extraction and longer live search/page fidelity checks.
- Economics/execution: calibrate cache, recovery and continuation forecasts before enabling cost-triggered mutations; measure matched long tasks for recovery, correction fidelity, completion, management overhead and total cost. Durable unattended workers and isolated execution remain unapplied.
