Use Conclave as an app

Install Conclave to open your dashboard from your home screen or desktop. If an Install Conclave button appears, select it. Otherwise, use your browser's menu to install the app or add it to your home screen. On iPhone or iPad, open Conclave in Safari, tap Share, then Add to Home Screen and enable Open as Web App if offered.

Sign in with your existing Conclave account. An internet connection is needed to load saved handoffs.

Only explicitly saved handoffs appear here. App and model labels are reported claims; a saved handoff does not show what an app currently remembers.
